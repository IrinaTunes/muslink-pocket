# Muslink Pocket

Офлайн-приложение для преподавателя музыкальной школы: ученики, занятия, доходы и долги.
Всё хранится локально в Room (SQLite), сеть не используется, разрешений кроме уведомлений нет.

- Язык интерфейса: русский
- Стек: Kotlin 1.9.24, Jetpack Compose (Material 3, BOM 2024.09.03), Navigation-Compose, Room 2.6.1 (KSP), ViewModel + StateFlow, Coroutines, WorkManager
- minSdk 26, targetSdk 35, compileSdk 35, AGP 8.7.2, Gradle 8.9

## Функциональность

1. **Главная** — доход за текущий месяц, общая сумма долгов, количество активных учеников, ближайшие пять занятий, сводка по месяцу (начислено / оплачено / осталось получить).
2. **Ученики** — список с поиском по имени и инструменту, добавление, редактирование, удаление (удаление ученика удаляет и его занятия). Поля: имя, инструмент, ставка за занятие, телефон, заметка. Для каждого ученика видна сумма долга.
3. **Занятия** — список, сгруппированный по датам (новые сверху), с итогом по дню. Добавление занятия: ученик, дата (Material 3 DatePicker), длительность, сумма (по ставке или вручную), отметка «оплачено». Переключение статуса оплаты в один тап, удаление с подтверждением.
4. **Итоги** — сводка по месяцам: начислено, оплачено, долг, число занятий. Экспорт всех занятий в CSV через SAF (`ACTION_CREATE_DOCUMENT`): дата, ученик, инструмент, длительность, сумма, статус. Файл в UTF-8 с BOM и разделителем `;` — открывается в Excel и Google Таблицах.
5. **Настройки** — ежедневное напоминание о занятиях на сегодня (вкл/выкл и время, по умолчанию 09:00). Реализовано через WorkManager + NotificationChannel: одно уведомление в день; если на сегодня занятий нет, уведомление не показывается. Здесь же — сведения о приложении и о хранении данных.

## Деньги

Все суммы хранятся в копейках (`Long`), без `float`/`double`. Форматирование — `1 500,50 ₽`, даты — `dd.MM.yyyy`.

## Сборка

Требуется JDK 17 и Android SDK (compileSdk 35).

```bash
# обязательно JDK 17
export JAVA_HOME=$(/usr/libexec/java_home -v 17)   # macOS

gradle :app:assembleDebug        # APK -> app/build/outputs/apk/debug/app-debug.apk
gradle :app:testDebugUnitTest    # юнит-тесты бизнес-логики
```

Wrapper в репозитории не поставляется — используется системный Gradle 8.9+ или
`gradle wrapper` для локальной генерации.

## Где скачать APK

CI собирает APK на каждый пуш в `main`:

1. Открыть вкладку **Actions** → workflow **Android CI** → последний успешный запуск.
2. Внизу страницы, блок **Artifacts** → `muslink-pocket-debug-apk`.
3. Распаковать архив — внутри `app-debug.apk`.

APK подписан debug-ключом CI и подходит для установки на устройство вручную
(`adb install app-debug.apk` или передать файл на телефон).

## Тесты

Юнит-тесты (JVM, без Android) проверяют бизнес-логику в `app/src/test/java/ru/muslink/pocket/domain/`:

- доход за месяц считается только по занятиям этого месяца;
- оплачено + долг = начислено;
- общий долг суммирует только неоплаченные занятия;
- сводка по месяцам агрегируется и сортируется;
- ближайшие занятия отфильтрованы по дате;
- форматирование и парсинг сумм в копейках.

## Ограничения

- Приложение **не тестировалось на реальном устройстве или эмуляторе** — проверена только компиляция, юнит-тесты и сборка APK в CI.
- Нет синхронизации и резервного копирования: данные живут в базе на одном устройстве.
- Нет расписания повторяющихся занятий — каждое занятие добавляется вручную.
- Уведомление зависит от политики энергосбережения производителя: WorkManager может отложить запуск.
- Экспорт не включает долги сводно по ученикам — только построчный список занятий.
